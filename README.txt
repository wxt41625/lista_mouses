PROYECTO: Inventario de Mouse

Archivos:
- main.py: menú principal y función main().
- datos.py: carga y guardado del archivo JSON.
- operaciones.py: funciones para agregar, mostrar, buscar, editar, eliminar y opciones nuevas.
- dispositivos.json: datos de prueba con 5 mouse.

IMPORTANTE:
El programa usa match-case, por lo que se recomienda Python 3.10 o superior.

Para ejecutarlo:
python3 main.py
